围绕高中教育做的一组在线工具，外加几个个人应用。绝大多数是纯静态网页，打开链接即可使用。

## 选科与志愿

- [北辰](https://yusheng266186-beep.github.io/beichen/) — 面向高一学生的 AI 选科陪伴：通过十轮谈心对话生成文理方位星图与 3+1+2 组合参考，现为线上正式版（[源码](https://github.com/yusheng266186-beep/beichen)）
- [北辰 v3](https://yusheng266186-beep.github.io/beichen-codex/) — 北辰的独立发布线：夜航 / 领航双模式、五幕谈心结构与重新设计的星图报告（[源码](https://github.com/yusheng266186-beep/beichen-codex)）
- [南溟](https://yusheng266186-beep.github.io/nanming/) — 高考目标探索：从选科与分数进入真实历年招生数据，结合 AI 谈心梳理兴趣，落在可核对的分数轴与航线图上（[源码](https://github.com/yusheng266186-beep/nanming)）
- [自我使用说明书](https://yusheng266186-beep.github.io/self-manual/) — 专业探索工具：从"什么事情会让你忘记时间"开始，通过连续情境对话看见自己的核心驱动与适合的专业方向（[源码](https://github.com/yusheng266186-beep/self-manual)）
- [落点](https://yusheng266186-beep.github.io/sichuan-gaokao-2026/v2/) — 四川 2026 高考志愿查询：院校专业组检索、组线分布筛选、冲稳保分档与同口径分数换算（[源码](https://github.com/yusheng266186-beep/sichuan-gaokao-2026)）

## 教学工具

- [质量慧析](https://yusheng266186-beep.github.io/zhiliang-huixi-new-/) — 本地优先的考试质量分析系统：年级、班级、学生到知识点的多层次分析，可导出 Word、PDF 与 Excel 报告（[源码](https://github.com/yusheng266186-beep/zhiliang-huixi-new-)）
- [成绩查询](https://yusheng266186-beep.github.io/grade-query/) — 班级成绩查询与发布工作台：老师导入模板即可加密发布，学生凭识别码查看个人报告与历次趋势（[源码](https://github.com/yusheng266186-beep/grade-query)）
- [研芽](https://yusheng266186-beep.github.io/yanya-planner/) — 30 天语文备考计划与打卡 PWA，支持离线使用（[源码](https://github.com/yusheng266186-beep/yanya-planner)）

## 其他项目

- [AURUM OS](https://yusheng266186-beep.github.io/) — 面向国内黄金市场的浏览器端决策工作台：行情观察、历史分析、情景预测与虚拟交易记录，数据由 GitHub Actions 定时更新（[源码](https://github.com/yusheng266186-beep/yusheng266186-beep.github.io)）
- [ZDiskCleaner Pro](https://github.com/yusheng266186-beep/zdisk-cleaner-pro) — Rust 编写的 Windows 磁盘清理工具：48 类缓存垃圾扫描、回收站管理与程序搬家，每次清理入账、可追溯还原（[下载](https://github.com/yusheng266186-beep/zdisk-cleaner-pro/releases)）
- [链动小铺](https://yusheng266186-beep.github.io/liandong-ai-radar/) — 公开可审计的 AI 数字商品价格与库存监测站，每小时自动采集，购买入口直达原商家（[源码](https://github.com/yusheng266186-beep/liandong-ai-radar)）
- [噗噗日记](https://github.com/yusheng266186-beep/pupu-diary) — Android 健康记录应用（Kotlin + Jetpack Compose），插画全部由 Canvas 代码手绘，数据本地优先（[下载](https://github.com/yusheng266186-beep/pupu-diary/releases)）
